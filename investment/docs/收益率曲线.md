# 利率期限结构

# 一、 收益率曲线 (Yield Curve)：市场的横截面观察

收益率曲线是利率期限结构的图形表达。它剔除信用风险因素，只反映”资金的时间价格”。

### 1.1 形态与含义

- **正向倾斜 (Normal)：**
- **含义：** 长期收益率高于短期收益率。投资者看好未来经济增长，同时要求为承担更长期限的风险获得额外补偿（期限溢价）。
- **例子：** 经济复苏阶段，银行1年期定存利率可能为 $1.5%$，5年期为 $2.5%$。资金锁定越久，要求的补偿越高。
- **反向倾斜/倒挂 (Inverted)：**
- **含义：** 短期收益率反而高于长期收益率，通常出现在货币紧缩叠加衰退预期的阶段。
- **例子：** 2023年下半年，美国国债市场出现深度倒挂。1个月期美债年化收益率达 **$5.5%$**，10年期却只有 **$4.0%$** 左右。市场认为高利率维持不住，衰退将迫使美联储降息，投资者宁可买入长债锁定未来10年的收益。

## 二、 息票剥离法 (Bootstrapping)：提取即期利率

实务中，附息债券的到期收益率（YTM）不能直接用于定价——它是不同期限现金流混合折现的结果。需要通过”息票剥离”（Bootstrapping）逐步算出各期限的**即期利率 (Spot Rate)**。

### 2.1 基本思路

把附息债券的每笔现金流拆开，当作独立的零息债券来定价。逐个期限求出即期利率后，就能为其他资产提供无套利的定价基准。

### 2.2 【例题一】2年期即期利率的提取

假设当前无风险市场（国债）数据如下（面值 100 元）：

1. **1年期零息债：** 价格 $97.00$ 元。

$$97.00 = \frac{100}{(1 + s\_1)^1} \Rightarrow s\_1 = 3.09%$$

1. **2年期附息债：** 票面利率 $5%$（年付息），当前市价 $102.00$ 元。
   根据无套利原则，现金流折现必须等于市价：

$$102.00 = \frac{5}{(1 + 3.09%)^1} + \frac{105}{(1 + s\_2)^2}$$

解得：**$s\_2 = 3.96%$**。

### 2.3 【例题二】3年期即期利率的递归求解

**要点：** Bootstrapping 是递归过程——必须先求出近端的即期利率，才能推算远端。

**已知：** 1年期即期利率 $s\_1 = 2.00%$；2年期即期利率 $s\_2 = 2.50%$。
**新增资产：** 一张3年期附息国债，票面利率 $4%$（年付息），市价 $103.50$ 元。求 $s\_3$。

**计算步骤：**

1. **定价等式：**

$$103.50 = \frac{4}{(1 + s\_1)^1} + \frac{4}{(1 + s\_2)^2} + \frac{104}{(1 + s\_3)^3}$$

1. **代入已知即期利率，剥离前两期：**

$$103.50 = \frac{4}{1.02} + \frac{4}{1.0506} + \frac{104}{(1 + s\_3)^3}$$

$$103.50 = 3.9216 + 3.8073 + \frac{104}{(1 + s\_3)^3}$$

1. **第3年现金流的现值：**

$$103.50 - 7.7289 = 95.7711 = \frac{104}{(1 + s\_3)^3}$$

1. **解出 $s\_3$：**

$$(1 + s\_3)^3 = \frac{104}{95.7711} \approx 1.0859 \Rightarrow s\_3 \approx 2.79%$$

3年期即期利率为 $2.79%$。

## 三、 远期利率 (Forward Rate)：隐含的未来借贷成本

远期利率不是对未来利率的预测，而是当前市场价格中**隐含**的未来借贷成本。企业常用它来做利率对冲。

### 3.1 基本原理

在无套利假设下，”连续持有两次短期资产”的终值，等于”直接持有一笔长期资产”的终值。

### 3.2 【例题一】1×2 远期：锁定明年的融资成本

**场景：** 某企业计划 **1年后** 启动新项目，届时需要借一笔 **1年期** 的资金。
**已知：** 当前1年期即期利率 $s\_1 = 3.09%$，2年期即期利率 $s\_2 = 3.96%$。

**计算：**

$$(1 + 3.96%)^2 = (1 + 3.09%)^1 \times (1 + f\_{1,2})$$

$$1.0808 = 1.0309 \times (1 + f\_{1,2}) \Rightarrow f\_{1,2} \approx 4.84%$$

**决策含义：** 市场隐含的明年利率为 $4.84%$。如果企业预判明年实际利率会超过 $5.5%$，现在就可以签远期利率协议 (FRA)，把借款成本锁定在 $4.84%$。

### 3.3 【例题二】2×3 远期利率

**场景：** 企业计划 **2年后** 开工新项目，届时需要借 **1年期** 资金。
**已知（承接上文）：** $s\_2 = 2.50%$，$s\_3 = 2.79%$。

**计算：**
逻辑：”直接存3年”的终值 = “先存2年，第2年末再按远期利率存1年”的终值。

$$(1 + s\_3)^3 = (1 + s\_2)^2 \times (1 + f\_{2,3})^1$$

$$(1 + 0.0279)^3 = (1 + 0.025)^2 \times (1 + f\_{2,3})$$

$$1.0860 = 1.0506 \times (1 + f\_{2,3}) \Rightarrow f\_{2,3} \approx 3.37%$$

**结论：** 市场隐含的“2年后起算的1年期远期利率”为 $3.37%$。

## 四、 综合应用：基于即期利率的定价与套利发现

即期利率曲线算出来之后，就可以用它在市场上寻找定价偏差，发现套利机会。这也是固定收益证券最核心的实务应用之一。

### 4.1 【综合例题】识别错误定价的企业债

**场景：** 已知无风险即期利率曲线：$s\_1 = 3.00%$，$s\_2 = 4.00%$。
市场上有一只2年期企业债，票面利率 $6%$（年付息），信用评级很高（暂不考虑违约），当前市价 **$102.50$ 元**。
**问题：** 这只债券定价合理吗？该买还是该卖？

**计算过程：**

1. **理论公允价值：**
   用即期利率曲线对现金流逐笔折现（不能用单一YTM）：

$$公允价值 = \frac{6}{(1 + 0.03)^1} + \frac{106}{(1 + 0.04)^2}$$

$$公允价值 = 5.825 + \frac{106}{1.0816}$$

$$公允价值 = 5.825 + 98.003 = 103.828 \text{ 元}$$

1. **与市场价格比较：**
   理论价值 **$103.828$ 元**，市价 **$102.50$ 元**，低估约1.3元。
   **结论：** 债券被低估，可以买入，等待价格向理论价值靠拢。

## 五、 期限结构理论

收益率曲线为什么会有不同形状？学术界主要有三种解释：

1. **纯粹预期假说 (Pure Expectations Hypothesis)**

- **核心观点：** 长期利率等于未来一系列短期利率预期的几何平均。曲线向上倾斜，说明市场预期未来央行会持续加息。

1. **流动性偏好理论 (Liquidity Preference Theory)**

- **核心观点：** 在预期理论基础上加了一层**期限溢价 (Term Premium)**。资金借出越久，通胀和宏观不确定性越大，投资者会要求额外补偿。

1. **市场分割理论 (Market Segmentation)**

- **核心观点：** 不同期限的债券市场各自独立，利率由各期限内的供需决定。比如银行偏好配短债做流动性管理，寿险公司为了久期匹配则大量买入超长期国债。长端和短端利率有时是被完全不同的参与者"交易"出来的。
