## 第二次实验任务

### 上市公司综合分类聚类分析

**数据来源**：tushare API
**Token**：由教师单独提供

---

### 一、任务目标

使用 tushare 获取上市公司财务、估值、运营数据，通过**聚类分析**将上市公司分为不同类型，并进行业务解读。

---

### 二、数据获取

| 项目 | 说明 |
|------|------|
| 数据源 | tushare Pro API |
| Token | 由教师单独提供 |
| 样本量 | 100-200家（随机抽取） |
| 时间 | 最新一期财报（截面数据） |

**tushare 接口**：
- `stock_basic` - 股票基本信息
- `fina_indicator` - 财务指标
- `valuation` - 估值指标
- `profit_data` - 盈利能力
- `operation_data` - 运营能力

---

### 三、数据维度

| 类别 | 指标 |
|------|------|
| 财务 | 总资产、净资产、负债率 |
| 估值 | 市盈率(PE)、市净率(PB)、市销率(PS) |
| 运营 | 毛利率、净利率、ROE、资产周转率、营收增长率 |

---

### 四、分析要求

#### 1. 数据获取（必做）
- 使用 tushare API 拉取上市公司数据
- 随机选取100-200家上市公司
- 整合多维度指标

#### 2. 数据清洗（必做）
- 缺失值检测与处理
- 异常值检测（可使用箱线图或3σ原则）
- 数据标准化

#### 3. 描述性分析（必做）
- 各指标分布情况
- 指标相关性分析（热力图）

#### 4. 聚类分析（必做）
- 使用 **KMeans** 聚类
- 聚类数量由学生自行判断（建议尝试2-5类）
- 分析各群体的特征差异

#### 5. 业务解读（必做）
- 各群体的特征总结
- 业务含义解释（如：成长型、价值型、稳健型等）

#### 6. 模型评估（必做）
- **交叉验证**（如轮廓系数）
- 聚类稳定性分析

---

### 五、可视化要求

- 特征分布图
- 相关性热力图
- 聚类结果可视化（如散点图降维）

---

### 六、输出要求

- **Jupyter Notebook**：代码+分析报告
- 中文输出
- 包含清晰的章节标题与分析结论

---

### 七、参考流程

```
数据获取 → 数据清洗 → 描述性分析 → 聚类分析 → 模型评估 → 业务解读 → 结论
```
