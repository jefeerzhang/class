### 一、任务目标

学生自行选定研究主题和分析目标，使用 tushare 获取上市公司相关数据，综合运用大数据分析方法完成研究任务，并给出有依据的业务解释和结论。

任务目标应由学生自主设定，例如但不限于：上市公司经营特征比较、行业内公司分组、财务风险识别、估值差异分析、成长性评价、投资价值筛选等。教师不直接指定统一结论，学生需要根据自己的目标完成数据获取、方法选择、分析过程和结果解释。

### 三、数据维度

数据维度由学生根据自定研究目标选择，不限定为固定的财务指标。可使用的数据类型包括但不限于：

| 类别 | 可选指标或数据 |
|------|------|
| 公司基本信息 | 行业、地区、上市时间、公司属性、主营业务等 |
| 财务数据 | 总资产、净资产、负债率、营业收入、净利润、现金流等 |
| 估值数据 | 市盈率(PE)、市净率(PB)、市销率(PS)、总市值、流通市值等 |
| 运营与成长数据 | 毛利率、净利率、ROE、资产周转率、营收增长率、利润增长率等 |
| 个股交易数据 | 收盘价、涨跌幅、成交量、成交额、换手率、振幅、复权价格等 |
| 其他数据 | 根据研究目标可补充行业指数、宏观变量、公告文本或新闻文本等 |

### 四、分析要求

#### 1. 数据获取（必做）
- 使用 tushare API 拉取上市公司数据
- 选取不少于200家上市公司
- 尽量选择同一大类业务类型或同一行业板块的公司
- 整合多维度指标

#### 2. 数据清洗（必做）
- 缺失值检测与处理
- 异常值检测（可使用箱线图或3σ原则）
- 数据标准化

#### 3. 描述性分析（必做）
- 各指标分布情况
- 指标相关性分析（热力图）

#### 4. 研究目标设定（必做）
- 明确说明自己设定的研究问题或任务目标
- 说明选择该目标的原因和业务意义
- 根据目标设计分析流程，并完成相应分析

#### 5. 大数据分析方法（必做）
- 使用不少于3种大数据分析方法
- 方法选择应服务于自定研究目标
- 可选方法包括但不限于：聚类分析、分类模型、回归分析、关联规则、降维分析、因子分析、异常检测、时间序列分析、文本分析、可视化分析等
- 对每种方法说明用途、主要结果和业务含义

#### 6. 模型评估（必做）
- 根据所使用的方法选择合适的评估指标
- 如使用聚类，可使用轮廓系数等指标
- 如使用分类或回归模型，应报告相应的预测效果或拟合效果
- 说明分析结果是否支持自己设定的研究目标

#### 7. 业务解读（必做）
- 总结主要发现
- 解释分析结果的业务含义
- 说明结论的适用范围和局限性
